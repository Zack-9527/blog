## 文本样式与排版

在日常写作中，常用文本强调格式如下：

* **加粗文本**：强调重点信息
* *斜体文本*：用于特定词汇或外文名词
* ~~删除线~~：标记废弃或更新的内容
* `单行代码 / 行内强调`：适合展示变量名、路径或命令
* <mark>高亮文本</mark>：突出显示关键字段

## 代码块展示

PaperMod 内置了良好的代码高亮与一键复制功能。

### Python 示例
```python
def calculate_factorial(n: int) -> int:
    """计算非负整数的阶乘"""
    if n < 0:
        raise ValueError("输入必须为非负整数")
    return 1 if n in (0, 1) else n * calculate_factorial(n - 1)

if __name__ == "__main__":
    result = calculate_factorial(5)
    print(f"5 的阶乘是: {result}")
